# GridRail AI

GridRail AI is the conversational project guide for GridGuard AI. It has completed core manual validation in a private ASU-managed ChatGPT workspace. Direct GPT sharing is currently limited to users recognized by that workspace. Other visitors may [submit an access request](https://docs.google.com/forms/d/e/1FAIpQLSddC199Z7tKwWrrFcPfUeZEiMqhM-7-hKzAlmLFpLpcesjSRA/viewform) to express interest, but submission does not guarantee access. The private canonical dataset is not exposed. Public GPT sharing is disabled by the ASU-managed workspace. External accounts are not currently directly shareable. No restricted GPT URL, knowledge package, configuration instructions or private dataset is published here.

[Access workflow](GRIDRAIL_ACCESS_WORKFLOW.md). [Live dashboard](https://gridguard-ai.pages.dev). Dashboard starter questions are retained in starters.json for interface parity tests. The dashboard does not generate AI answers.
