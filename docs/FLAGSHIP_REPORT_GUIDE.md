# Scientific report guide

Use [Methods](METHODS.md), [Results](RESULTS.md), [Data Card](DATA_CARD.md) and [Limitations](LIMITATIONS.md) for the current project scope. Cite literature using verified records in [Literature Review](LITERATURE_REVIEW.md).

The report describes a synthetic DC benchmark, not utility safety. Completed local heuristic, per-scenario and bootstrap evidence is reported separately from fresh cloud results. Scores are rankings rather than calibrated failure probabilities. The fresh test is not evaluated. Do not transfer a local or historical metric into the fresh run. Do not invent missing curve points or a cause for RF variation.
