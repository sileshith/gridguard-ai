# Attribution and release scope

The repository retains its [MIT code license](../LICENSE) for original GridGuard software. That notice does not grant rights in third-party benchmark data or restricted course material.

Historical evidence identifies MATPOWER IEEE 118-bus lineage. The upstream [case118 source](https://github.com/MATPOWER/matpower/blob/master/data/case118.m) identifies conversion from the [University of Washington power systems archive](https://labs.ece.uw.edu/pstca/). The exact case revision used by the missing generator remains unknown.

The [MATPOWER license](https://github.com/MATPOWER/matpower/blob/master/LICENSE) covers its software under BSD terms and explicitly excludes its case files from that grant. Canonical private CSV redistribution permission has not been established. No canonical private CSVs, model binaries, benchmark case files, MATPOWER routines or restricted course files are included in the public candidate. No broader permission is inferred.

The bounded release review found no vendored restricted course or MATPOWER implementation in the source/docs candidate. This is a recorded source/docs-only licensing outcome, not a grant of rights in excluded inputs or exhaustive legal certification. Dependencies remain external packages under their upstream notices.

Sileshi T. Hirpa's Arizona State University affiliation is descriptive, not university endorsement. The project originated in CIS 415 and adds independent portfolio engineering. No university marks or restricted course files are redistributed.

This source/docs release excludes canonical data and third-party case files. Canonical-data redistribution remains prohibited under the current project policy.
